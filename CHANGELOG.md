# Changelog

## 0.1.0

First version.

- Chat with Pia in simple German: letters (Word/PDF), lists and spreadsheets, small web pages, photo explanations, help with Windows settings.
- Locked to `Dokumente\Pia`. Nothing is ever deleted; older versions can be brought back.
- Limits per request, with a plain "Ja, mach das" question for bigger jobs.
- ChatGPT sign-in by device code, approved on the helper's phone.
- Friendly usage-limit pause that says when Pia is back.
- "Jetzt aktualisieren" button for new versions; required versions via `update-policy.json`.
