# Pia einrichten (für dich, nicht für Mama)

Dauert etwa 10 Minuten. Du brauchst dein Handy, auf dem du bei ChatGPT angemeldet bist.

## 1. Installieren

1. Auf ihrem PC die neueste `Pia_x.y.z_x64-setup.exe` von der Releases-Seite herunterladen:
   https://github.com/NAM-likestocode/pia/releases/latest
2. Starten. Windows zeigt beim ersten Mal **"Der Computer wurde durch Windows geschützt"**. Auf **"Weitere Informationen"** und dann **"Trotzdem ausführen"** klicken. Das passiert nur bei der ersten Installation, Updates laufen ohne diese Meldung.
3. Die Installation braucht keine Administratorrechte. Danach liegt Pia im Startmenü und auf dem Desktop.

## 2. Helfer-PIN festlegen

1. Pia öffnen. Unten rechts auf **"Einstellungen für Helfer"** klicken.
2. Eine PIN (4 bis 8 Ziffern) festlegen, die nur du kennst.

## 3. Mit ChatGPT anmelden

1. Im Helfer-Bereich auf **"Mit ChatGPT anmelden"** klicken.
2. Pia zeigt einen Code und eine Adresse (auth.openai.com/codex/device).
3. Die Adresse **auf deinem Handy** öffnen, den Code eingeben und bestätigen.
   Wichtig: **nicht** auf ihrem PC im Browser anmelden, sonst wäre ihr Browser in deinem ChatGPT-Konto angemeldet und sie könnte deine Gespräche sehen.
4. Pia meldet "Angemeldet. Pia ist bereit."

## 4. Einstellungen prüfen

- **Modell / Denken:** Die Vorgaben passen meistens. Mehr Denken ist gründlicher, aber langsamer und verbraucht mehr vom Kontingent.
- **Funktionen:** Alles abschalten, was sie nicht braucht.
- **Grenzen:** wie viele Dateien und Schritte pro Anfrage, mit und ohne ihr "Ja, mach das".
- **"Fertig"** sperrt den Helfer-Bereich wieder (das passiert auch automatisch nach 15 Minuten).

## 5. Kurz mit ihr ausprobieren

- "Schreib einen Brief an meine Krankenkasse, dass ich umgezogen bin."
- Ein Foto von einem Brief oder einer Fehlermeldung schicken.
- "Wie mache ich die Schrift größer?" → Pia öffnet die passende Einstellungsseite und erklärt sie.

Ihre Dateien liegen in **Dokumente\Pia**. Ältere Versionen holt man unter **"Meine Dateien" → "Ältere Versionen"** zurück.

## Wenn etwas nicht geht

| Sie sieht | Was tun |
|---|---|
| "Pia ist noch nicht ganz eingerichtet" / "nicht angemeldet" | Schritt 3 wiederholen. |
| "Ich brauche eine Pause … bin ich wieder da" | Das ChatGPT-Kontingent ist aufgebraucht. Warten, Pia sagt selbst, wann sie wieder da ist. |
| "Es gibt eine neue Version von Pia" | Auf "Jetzt aktualisieren" klicken. Pia startet danach neu. |
| "Ich komme gerade nicht ins Internet" | WLAN prüfen. |
